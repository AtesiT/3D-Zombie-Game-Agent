# «Ночь аэродрома» — 3D Zombie FPS

Одностраничная браузерная игра от первого лица в духе **Call of Duty: World at War Zombies**. Вся клиентская игра находится в `index.html` (Three.js r147 через CDN, процедурные текстуры и WebAudio); `server.js` — небольшой необязательный сервер для WebSocket-кооператива и онлайн-таблицы рекордов.

Карта по мотивам компактной планировки Nacht der Untoten: стартовая комната с баррикадами, отдельная комната **HELP!** с Mystery Box, лестница и два помещения второго этажа. Классическую схему расширяет доступный для прогулки двор аэродрома с разбитым самолётом, проволочным ограждением, грязью/снегом и обзорной вышкой. Это авторская игровая интерпретация, а не точная копия оригинальных ассетов.

## Запуск

### Полная версия — включая онлайн-кооп и рекорды

Нужен Node.js 18 или новее; дополнительные npm-пакеты не нужны:

```bash
node server.js
# открыть http://localhost:8001
```

`server.js` раздаёт `index.html`, ретранслирует WebSocket-сообщения комнат и сохраняет таблицу в локальный `.leaderboard.json` (файл игнорируется Git).

### Только локальная игра

Можно запустить любой статический сервер, например:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

В этом варианте работают одиночная игра и кооператив между вкладками одного браузера через `BroadcastChannel`; для связи между разными устройствами нужен `node server.js`.

## Карта

```text
               ┌─────────────────────────────┐
               │ ВЕРХНИЙ ЭТАЖ — ЗАПАД/ВОСТОК │
               │ 4 окна · оружие · Pack-a-Punch│
               └───────────┬─────────────────┘
                           │ лестница / завал — 1000
┌────────────────────┐     │
│ КОМНАТА РОЖДЕНИЯ   ├─────┴───┐
│ 5 окон, оружие,     │ дверь   │ КОМНАТА «HELP!»
│ начало волн        │ 1000    │ Mystery Box · Juggernog
└────────────────────┘         └──── дверь 1000 ────┐
                                                    │
                                      ДВОР АЭРОДРОМА│
                                      разбитый самолёт
                                      прогулочная зона
                                      лифт → вышка
```

- **Первый этаж:** комната появления и комната HELP! с разбираемыми окнами.
- **Второй этаж:** два поднятых на 4 метра помещения с отдельными коллизиями, потолком и окнами; лестничная шахта ведёт через перекрытие.
- **Двор:** открытая площадка за воротами HELP!, ограниченная ограждением. Здесь есть транспортный самолёт, мешки, трава/снег, скалы на горизонте и лифт на верхнюю площадку.
- Двери стоят 750–1000 очков и открывают новые зоны и точки появления.
- В меню можно выбрать **Nacht** или процедурную снежную версию аэродрома. Позиции наружного декора строятся по seed; ежедневное испытание получает seed текущей даты.

## Управление

| Действие | Клавиша / устройство |
|---|---|
| Движение / бег | `W A S D` / `Shift` |
| Обзор | мышь и Pointer Lock; на телефоне — свайп |
| Огонь / прицел | ЛКМ / ПКМ |
| Перезарядка / взаимодействие | `R` / `F` |
| Граната / нож / альтернативный огонь | `G` / `V` / `B` |
| Слоты оружия | `1` / `2` |
| Пауза / звук | `Esc` или `P` / `M` |
| Запасной поворот | `Q` / `E`, если Pointer Lock недоступен |
| Геймпад | левый стик — ходьба, правый — обзор; кнопки действия переназначаются в меню |

Клавиши и кнопки геймпада можно переназначить в стартовом меню. Схема сохраняется локально. На сенсорном экране появляются джойстик движения и кнопки огня, прицела, ножа, alt-огня, гранаты и действий.

## Режимы и прогресс

- **Выживание:** бесконечные волны, растущие характеристики врагов.
- **Забег на 3 минуты:** нужно продержаться до таймера.
- **Ежедневное испытание:** seed дня и изменённые плотность волн/скорость противников.
- Автосохранение чекпоинта с возможностью продолжить забег после перезагрузки.
- Личные рекорды и достижения сохраняются в `localStorage`; онлайн-таблица доступна при запуске `server.js`.
- Настройки сложности: здоровье/скорость/урон зомби, плотность спавна и награда за убийство.
- Графика: высокая / средняя / производительная; трава, снег и дальние объекты используют `InstancedMesh`.

## Кооператив

1. Запустите `node server.js`.
2. В двух браузерах/устройствах откройте `http://<адрес-сервера>:8001`.
3. Введите одинаковый код комнаты и нажмите **Сетевой кооп**.
4. Начните бой. Игроки видны друг другу; сервер передаёт позиции, состояние волн и зомби, попадания, урон и открытые двери.

Если WebSocket-сервер недоступен, игра сохраняет локальный вариант кооператива через `BroadcastChannel` для вкладок одного браузера.

## Системы игры

- M1911, MP-40, Trench Gun, два слота, Mystery Box, Ray Gun и Вундерваффе DG-2.
- Вторичный точный выстрел (расходует два патрона) и ближний бой ножом.
- Pack-a-Punch, 5 перков, павер-апы, гранаты, электрические ловушки и автоматическая турель.
- Обычные зомби, бегуны, танки, ползуны, кислотные плевуны, собаки и босс каждые 10 волн.
- У босса три фазы, разрушаемые бронепластины, уязвимое ядро и удар по земле.
- Окна: зомби разбирают доски, игрок чинит их за очки.
- Пасхалка: 3 радиозаписи и 3 вентиля заряжают телепорт и открывают альтернативный экран победы.
- Raycasting, трассеры, вспышки, звук WebAudio, меню старта/паузы/поражения/победы.

## Проверка

Клиент проверен headless-набором (jsdom + Three.js): регрессия старых систем, слои карты и лестница, выход во двор, лифт, баррикады, двери и покупки, все типы врагов, оружие, гранаты, перки, бонусы, пасхалка, настройки, рекорды, таймер и чекпоинт — **все проверки пройдены**. Дополнительно проверены HTTP-эндпоинты и ретрансляция двух WebSocket-клиентов; игровой бот прошёл 5 минут симуляции без исключений.
