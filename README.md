# 3D-Zombie-Game-Agent — «НАЧАЛО КОНЦА»

Одностраничный 3D-шутер от первого лица (FPS) в стиле режима «Зомби» из Call of Duty.
Вся игра — **один файл `index.html`**: HTML + CSS + JavaScript (ES6+), 3D на **Three.js r147** (подключён через CDN jsDelivr, с резервным unpkg).

## Как запустить
Откройте `index.html` в браузере (нужен интернет — Three.js грузится с CDN) либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000/
```

## Управление
| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | перемещение относительно взгляда |
| Мышь | обзор (Pointer Lock — клик по экрану) |
| `ЛКМ` | огонь (автомат — зажим) |
| `ПКМ` | прицеливание |
| `R` | перезарядка |
| `F` | открыть дверь / купить оружие на стене |
| `Shift` | бег |
| `Q` / `E` | поворот (резервный режим, если курсор не захватывается) |
| `M` | звук вкл/выкл, `Esc` — пауза |

## Что реализовано
- **Карта из 5 зон** (холл → северный коридор → реакторный зал, оружейная, лаборатория) с 4 покупаемыми дверями (750 / 1250 / 1750 / 2000 очков); открытие двери активирует новые точки спавна зомби.
- **Волны**: растут количество, здоровье, скорость и урон; типы зомби — обычные, «бегуны» (с 6-й волны) и «танки» (с 5-й).
- **Экономика**: +10 за попадание, +60 за убийство, 500 очков на старте, покупки на стенах (пистолет 500, автомат MP-40 1000, дробовик Trench Gun 1500), повторная покупка пополняет патроны.
- **Оружие**: M1911 (одиночные), MP-40 (автоогонь зажимом), Trench Gun (5 лучей веером) — у каждого своя 3D-модель в руках, темп, урон, разброс и отдача.
- **Боевая механика**: `THREE.Raycaster` из центра экрана, множители урона по частям тела (голова ×2.6, конечности ×0.75), вспышка урона красным, трассеры, искры, кровь и декали, метка попадания.
- **ИИ зомби**: движение к игроку, локальный обход препятствий, маршрутизация через открытые двери по дереву зон, расталкивание в толпе, «выползание» из-под земли, страховка от вечного залипания.
- **Атмосфера**: рассеянный свет низкой интенсивности, фонарик-прожектор у камеры, мерцающие аварийные лампы, туман, затемнение по краям, регенерация здоровья через 5 секунд без урона.
- **Интерфейс**: прицел с динамическим разбросом, очки (слева снизу), здоровье и патроны (справа снизу), крупный красный номер волны, экраны старта/паузы/смерти со статистикой, всплывающие подписи над дверями и покупками.
- **Звук**: полностью процедурный синтез на WebAudio (выстрелы, рычание, покупки, волны) — без внешних файлов.

## Замечания
- Тени намеренно отключены ради производительности при толпах зомби; вся графика — процедурные canvas-текстуры и примитивы.
- Проверено headless-тестами (jsdom + настоящий three.js): коллизии, стрельба, покупки, волны, рестарт, 3-минутный авто-прогон ботом.
