# 3D-Zombie-Game-Agent — «НАЧАЛО КОНЦА»

Одностраничный 3D-шутер от первого лица (FPS) в стиле режима «Зомби» из Call of Duty.
Вся игра — **один файл `index.html`**: HTML + CSS + JavaScript (ES6+), 3D на **Three.js r147**
(подключён через CDN jsDelivr, с резервным unpkg). Никаких внешних ассетов: все текстуры
рисуются на canvas, звук синтезируется через WebAudio, модели собраны из примитивов.

## Как запустить

Откройте `index.html` в браузере (нужен интернет — Three.js грузится с CDN) либо поднимите сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000/
```

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | перемещение относительно взгляда |
| Мышь | обзор (Pointer Lock — клик по экрану) |
| `ЛКМ` | огонь (автомат — зажим) |
| `ПКМ` | прицеливание |
| `R` | перезарядка |
| `F` | взаимодействие: двери, покупки на стенах, перки, ящик тайн, Pack-a-Punch, окна, радио, вентили, телепорт |
| `G` | граната |
| `1` / `2` | слоты оружия (2 ствола) |
| `Shift` | бег |
| `Q` / `E` | поворот (резервный режим, если курсор не захватывается) |
| `M` | звук вкл/выкл, `Esc` — пауза |

На тач-устройствах автоматически включается мобильное управление: джойстик слева, свайп — обзор,
кнопки справа — огонь, прицел, перезарядка, `F`, граната, смена оружия.

## Карта

5 зон, соединённых покупаемыми дверями (750 / 1250 / 1750 / 2000 очков):

```
                [РЕАКТОРНЫЙ ЗАЛ]  <- 2000 (телепорт-пасхалка, Stamin-Up, ловушка)
                        |
   [ОРУЖЕЙНАЯ] <- 1250 - [БЛОК «Б» — ХОЛЛ] - 750 -> [СЕВЕРНЫЙ КОРИДОР]
        (PaP, Juggernog)  (старт, ящик, турель,   (Speed Cola, дробовик,
                           ловушка, окна)          окно, вентиль)
                        |
             1750 -> [ЛАБОРАТОРИЯ]  (Double Tap, дробовик)
```

Открытие двери активирует новые точки спавна зомби в этой зоне.

## Реализованные системы

**Бой и оружие**
- Raycasting из центра экрана; множители урона по частям тела (голова ×2.6, конечности ×0.75),
  красная вспышка урона, трассеры, искры, кровь, декали, метка попадания.
- Оружие: M1911 (8/80), MP-40 (32/320, автоогонь), Trench Gun (6/60, 5 лучей веером),
  чудо-оружие из ящика: Ray Gun (урон по площади) и Вундерваффе DG-2 (площадь + электроцепь).
- Два слота оружия со своими патронами и уровнем улучшения, переключение `1`/`2`.
- Гранаты (`G`) с физикой, отскоками и уроном по площади; гранаты пополняются бонусом «макс. патроны».

**Экономика и апгрейды**
- +10 за попадание, +60 за убийство, 500 очков на старте, множитель ×2 от «двойных очков».
- Покупки на стенах: пистолет 500, автомат 1000, дробовик 1500 (повторная покупка = патроны).
- **Ящик тайн (950)** — случайное оружие с анимацией, шансом на чудо-оружие и медвежонком-обманкой.
- **Pack-a-Punch (5000)** — удваивает урон и магазин, золотит модель.
- **5 перков**: Quick Revive (самовоскрешение), Juggernog (250 HP), Double Tap (×2 урон),
  Stamin-Up (+30% скорости), Speed Cola (перезарядка вдвое быстрее).
- **Ловушки** (1250, 22 с электричества) и **турель** (2000, 3 заряда) — автоматически бьют зомби.

**Волны и зомби**
- Рост количества, здоровья, скорости и урона; ограничение одновременных зомби ради FPS.
- Типы: обычные, «бегуны», «танки», «ползуны» (низкие и быстрые), «плевуны» (кислотные снаряды),
  **собаки** (каждая 3-я волна начиная с 5-й, быстрые четвероногие) и **босс** каждые 10 волн (аура, ×14 HP).
- ИИ: движение к цели, локальный обход препятствий, маршрутизация через открытые двери по дереву зон,
  расталкивание в толпе, «выползание» из-под земли, страховки от вечного залипания и затянувшихся волн.
- **Окна-баррикады**: зомби разбирают доски, игрок чинит их за `F` (+10 очков за доску), через открытые окна лезут внутрь.

**Бонусы из убийств**
Мгновенная смерть (×400 урона), Двойные очки (×2 начисления), Макс. патроны, Ядерный взрыв (+400 и всё живое),
Распродажа (ящик за 150). Выпадают с шансом ~4.5% и гарантированно с босса.

**Пасхалка**
3 радио-записи + 3 вентиля топлива → заряжается **телепорт** в реакторном зале → экран победы со статистикой.

**Интерфейс и мета-прогрессия**
- HUD: прицел с динамическим разбросом, очки, здоровье, патроны, гранаты, слоты, иконки перков,
  таймеры бонусов, крупный номер волны, подписи над дверями/покупками/устройствами.
- Экраны старта (рекорды + достижения + пульт баланса), паузы, смерти и победы.
- **10 достижений** и **рекорды** (лучшая волна, убийства, время, число игр) в `localStorage`.
- **Пульт баланса**: ползунки здоровья/скорости/урона зомби, плотности спавна и очков + пресеты «Легко/Обычно/Хардкор».
- **Кооп-режим**: 2 игрока в двух окнах/вкладках одного браузера, синхронизация через `BroadcastChannel`
  (позиция, поворот, HP, волна, очки партнёра видны в HUD).

## Технические заметки

- Тени отключены ради производительности при толпах зомби; вся геометрия — примитивы и процедурные canvas-текстуры.
- Стены — единый BufferGeometry с корректными UV, коллизии — круг против прямоугольников через
  пространственный индекс; ИИ использует локальные «щупы» плюс маршрутизацию по зонам.
- Свет: рассеянный (Ambient), фонарик-SpotLight у камеры, мерцающие аварийные лампы, точечные акценты устройств.
- Проверено headless-тестами (jsdom + настоящий three.js): ~140 проверок — коллизии, стрельба, покупки,
  перки, ящик, PaP, ловушки, турель, окна, пасхалка, бонусы, гранаты, слоты, достижения, рекорды, баланс, кооп,
  плюс 5-минутный авто-прогон ботом без ошибок.
